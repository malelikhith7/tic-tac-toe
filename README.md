 # Tic Tac Toe Game

A simple, interactive two-player Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Live Demo

Play the game here: https://malelikhith7.github.io/tic-tac-toe/

## Features

- Two-player gameplay using X and O
- Automatic winner detection
- Draw detection
- Highlights the winning combination
- Reset Game and New Game buttons
- Responsive design

## Technologies Used

- HTML5 – Game structure
- CSS3 – Styling and responsive layout
- JavaScript – Game logic, player turns, win detection, and reset functionality

## Project Structure

- `index.html` – Game structure
- `style.css` – Game styling
- `app.js` – Game logic

## How to Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start playing!

- Working with arrays and winning combinations
- Implementing interactive game logic
- Connecting HTML, CSS, and JavaScript
